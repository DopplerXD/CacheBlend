# 实验脚本汇总

## 1. blend.py

最小演示脚本，用固定 10 条样本对比 full_prefill、full_reuse、kv_diff、query_aware 四种方法。

- 基本流程设计：
  - 初始化 `RuntimeConfig`、模型、KV 缓存和推理引擎。
  - 读取 inputs/1.json, 2.json, ..., 10.json。
  - 为每条样本构造文档前缀、真实问题 prompt 和旧缓存占位 prompt。
  - 先跑 `full_prefill` 与 `full_reuse`，再基于旧缓存分别跑 `kv_diff` 与 `query_aware`。
  - 逐条写 `sample_result`，最后写 `run_summary`。
- 主要参数：
  - `--model-name`
  - `--methods all|baselines_only`
- 输出位置：
  - `outputs/*_blend.output`
  - `outputs/*_blend_console.output`
- 示例命令：

```bash
python example/blend.py
python example/blend.py --model-name /root/models/Yi-6B
python example/blend.py --methods baselines_only
```

## 2. blend_musique.py

- 作用：MusiQue 主实验脚本，在多文档问答数据上比较 `full_prefill`、`full_reuse`、`query_aware`。
- 基本流程设计：
  - 读取 `inputs/musique_s.json`。
  - 对每条样本构造 `doc_prompts`、真实问题 prompt 和旧缓存占位 prompt。
  - 顺序运行 `full_prefill`、`full_reuse`、`query_aware`。
  - 记录生成结果、TTFT、总时延、F1、是否触发真实重算。
  - 输出逐样本结果和整次实验汇总。
- 主要参数：
  - `--count`
  - `--qaw-ratio`
  - `--output-dir`
- 输出位置：
  - 默认 `outputs/*_musique.output`
- 示例命令：

```bash
python example/blend_musique.py
python example/blend_musique.py --count 50 --qaw-ratio 0.7
python example/blend_musique.py --output-dir outputs/useful
```

  - 对嵌套答案结构做归一化后计算 F1。
  - 输出逐样本结果和整次实验汇总。
- 主要参数：
  - `--count`
  - `--qaw-ratio`
  - `--output-dir`
- 输出位置：
  - 默认 `outputs/*_wikimqa.output`
- 示例命令：

```bash
python example/blend_wikimqa.py
python example/blend_wikimqa.py --count 50 --qaw-ratio 0.7
```

## 5. blend_curve.py

- 作用：统一的 ratio 曲线实验脚本，固定 `suffix_len`，扫描一组 `qaw_ratio`。
- 基本流程设计：
  - 根据 `--dataset` 从公共数据集规格中读取数据集路径和 prompt 模板。
  - 先运行一次 baseline 统计 `full_prefill`，部分数据集还会统计 `full_reuse`。
  - 对每条样本建立旧缓存，再对一组 `qaw_ratio` 逐个运行 `query_aware`。
  - 每个 ratio 只写一条 `run_summary`，用于后续画曲线。
- 主要参数：
  - `--dataset`
  - `--model-name`
  - `--count`
  - `--qaw-ratio-min`
  - `--qaw-ratio-max`
  - `--qaw-ratio-step`
  - `--suffix-len`
  - `--output-dir`
  - `--run-tag`
- 输出位置：
  - 默认 `outputs/*_<dataset>_curve.output`
- 示例命令：

```bash
python example/blend_curve.py --dataset musique
python example/blend_curve.py --dataset wikimqa --count 50 --qaw-ratio-min 0.25 --qaw-ratio-max 1.0
python example/blend_curve.py --dataset cmrc --model-name /root/models/Qwen2.5-1.5B --suffix-len 32
```

## 6. blend_suffix_curve.py

- 作用：统一的 `suffix_len` 曲线实验脚本，固定 `qaw_ratio`，扫描一组 `suffix_len`。
- 基本流程设计：
  - 加载指定数据集与模型。
  - 先运行 baseline 统计。
  - 对每条样本基于旧缓存运行多组不同 `suffix_len` 的 `query_aware`。
  - 每个 `suffix_len` 输出一条 `run_summary`。
- 主要参数：
  - `--dataset`
  - `--model-name`
  - `--count`
  - `--qaw-ratio`
  - `--suffix-len-min`
  - `--suffix-len-max`
  - `--suffix-len-step`
  - `--output-dir`
  - `--run-tag`
- 输出位置：
  - 默认 `outputs/*_<dataset>_suffix_curve.output`
- 示例命令：

```bash
python example/blend_suffix_curve.py --dataset musique
python example/blend_suffix_curve.py --dataset musique --count 50 --qaw-ratio 0.7 --suffix-len-step 8
python example/blend_suffix_curve.py --dataset cmrc --model-name /root/models/Qwen2.5-1.5B
```

## 7. blend_ratio_suffix_curve.py

- 作用：统一的二维网格实验脚本，同时扫描 `qaw_ratio` 和 `suffix_len`。
- 基本流程设计：
  - 读取指定数据集并初始化模型。
  - 先跑 baseline 统计。
  - 对每条样本建立旧缓存后，遍历 `ratio x suffix_len` 的网格组合运行 `query_aware`。
  - 每个组合输出一条 `run_summary`，便于后续做热力图或二维比较。
- 主要参数：
  - `--dataset`
  - `--model-name`
  - `--count`
  - `--qaw-ratio-min`
  - `--qaw-ratio-max`
  - `--qaw-ratio-step`
  - `--suffix-len-min`
  - `--suffix-len-max`
  - `--suffix-len-step`
  - `--output-dir`
  - `--run-tag`
- 输出位置：
  - 默认 `outputs/*_<dataset>_ratio_suffix_curve.output`
- 示例命令：

```bash
python example/blend_ratio_suffix_curve.py --dataset musique
python example/blend_ratio_suffix_curve.py --dataset wikimqa --count 50
python example/blend_ratio_suffix_curve.py --dataset cmrc --model-name /root/models/Qwen2.5-1.5B
```

## 8. 0416_sum.py

- 作用：批量调度脚本，顺序执行预先写死的 5 个实验任务。
- 基本流程设计：
  - 在 `outputs/0416_sum/` 下创建汇总输出。
  - 按任务列表依次调用子实验脚本。
  - 每个子任务完成后加载对应 `run_summary`。
  - 如果子任务异常，则把异常信息补写到该任务输出文件中。
  - 每个任务结束后单独执行一次显存清理。
  - 最后写整个调度过程的 `run_summary`。
- 主要参数：
  - 无 CLI 参数，任务列表写在脚本内部。
- 输出位置：
  - `outputs/0416_sum/`
- 示例命令：

```bash
python example/0416_sum.py
```

## 9. 0417_sum.sh

- 作用：顺序执行一组 CMRC 相关实验命令的 shell 清单。
- 基本流程设计：
  - 先运行 `blend_cmrc.py`
  - 再运行 `blend_curve.py --dataset cmrc`
  - 最后运行 `blend_suffix_curve.py --dataset cmrc`
- 主要参数：
  - 无脚本内参数，命令参数直接写死在脚本内容里。
- 输出位置：
  - 各子命令仍写各自默认输出目录 `outputs/`
- 示例命令：

```bash
bash example/0417_sum.sh
chmod +x example/0417_sum.sh && ./example/0417_sum.sh
```

## 10. blend_curve_common.py

为 blend_curve.py、blend_suffix_curve.py、blend_ratio_suffix_curve.py 提供公共逻辑。

- 主要内容：
  - 数据集规格表 `DATASET_SPECS`
  - prompt 构造辅助函数
  - baseline 统计逻辑
  - QAW 网格评测逻辑
  - 曲线 `run_summary` 拼装逻辑

## 11. utils.py

提供实验脚本共用的基础处理函数。

主要内容：

- 数据读取
- 问题规范化
- QA prompt 构造
- 生成文本规范化
- F1 计算
