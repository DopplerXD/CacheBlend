# 实验脚本汇总

当前实验主线使用 chunk 级 KV 缓存。每条样本先将 `chunk_texts` 独立预热到 chunk KV 池，再比较 `full_prefill`、`full_reuse` 与 `query_aware`。

## 主实验脚本

### `example/blend.py`

- 小规模 demo，读取 `inputs/1.json` 到 `inputs/10.json`。
- 输出 `full_prefill`、`full_reuse`、`query_aware` 的生成结果、TTFT、总时延和 chunk 命中统计。

```bash
python example/blend.py
python example/blend.py --model-name /root/models/Yi-6B --qaw-ratio 0.5
```

### `example/blend_musique.py`

- 数据集：`inputs/musique_s.json`
- 指标：F1

```bash
python example/blend_musique.py --count 50 --qaw-ratio 0.7
```

### `example/blend_wikimqa.py`

- 数据集：`inputs/wikimqa_s.json`
- 指标：F1

```bash
python example/blend_wikimqa.py --count 50 --qaw-ratio 0.3
```

### `example/blend_cmrc.py`

- 数据集：`inputs/cmrc_s.json`
- 指标：F1
- 常用 Qwen 模型运行。

```bash
python example/blend_cmrc.py --model-name /root/models/Qwen2.5-1.5B --count 50 --qaw-ratio 0.7
```

### `example/blend_samsum.py`

- 数据集：`inputs/samsum.json`
- 指标：Rouge-L

```bash
python example/blend_samsum.py --count 100 --qaw-ratio 0.7
```

## 曲线脚本

### `example/blend_curve.py`

- 统一 ratio 曲线脚本。
- 支持 `musique`、`wikimqa`、`cmrc`、`samsum`。
- `suffix_len` 不再是主参数；兼容参数会被忽略。

```bash
python example/blend_curve.py --dataset musique --count 50 --qaw-ratio-min 0 --qaw-ratio-max 1 --qaw-ratio-step 0.05
python example/blend_curve.py --dataset samsum --count 50 --qaw-ratio-min 0 --qaw-ratio-max 1 --qaw-ratio-step 0.05
```

## 输出字段

逐样本日志包含：

- `warm_chunk_cache_hits`
- `warm_chunk_cache_misses`
- `chunk_cache_hits`
- `chunk_cache_misses`
- `recomputed_tokens`
- `recompute_mode`
- `ttft_s`
- `total_s`
- `f1` 或 `rougeL`

汇总日志包含各方法平均 TTFT、平均总时延、平均质量指标和 QAW 真重算次数。
